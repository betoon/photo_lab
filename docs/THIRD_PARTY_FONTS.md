# Third-party fonts

## Michroma

PhotoLab bundles the unmodified Michroma Regular font for application titles,
major tabs, section headings, and selected feature controls.

- Copyright 2011 The Michroma Project Authors
- Source: https://github.com/google/fonts/tree/main/ofl/michroma
- License: SIL Open Font License, Version 1.1
- Bundled license: `assets/fonts/michroma/OFL.txt`

Michroma is used as a display face. PhotoLab retains Segoe UI (or the operating
system's substitute) for dense controls, menus, values, tooltips, and long text.
